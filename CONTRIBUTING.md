# Contributing

Keep this repository free of game content and other people's work:

- No game files or anything extracted from them: packages (`.xxx`, `.psf`), exported `.glb`/`.blend` files,
  textures, skeletons, animations, audio, or screenshots used as data.
- No game executables, DLLs, symbol files, keys, memory dumps or decompiler/disassembler output. Write code from your
  understanding of the file format; don't copy or translate code from the game or from reverse-engineering tools.
- No code, patterns or instructions that patch, hook or inject into the game, or that disable or bypass its integrity
  checks, DRM, anti-cheat or online services.
- No entitlement or access-control bypass. The tool may process any file already present in the user's own
  installation, base game and DLC alike, but must never: unlock content the user does not own; bypass Steam or game
  entitlement checks; patch the game to enable unowned content; download game or DLC files from any source; decrypt or
  bypass access controls to obtain content; or provide missing paid-content files.
- No third-party characters, models or assets unless you have the right to share them under this project's license.
- No personal paths, logs, settings or mod-folder contents (`exports`, `converted`, `mod_projects`, `created_mods`).
- No example mods or Mod Projects made from game data. Test Mod Projects must be generated by the tests from synthetic
  models, images and manifests.
- Mod Project code must keep `mod.json` a pure recipe: no embedded game data (mesh, texture or package bytes, Base64
  copies, binary patches containing copied package sections), nothing that can run commands, download files or reach
  outside the Mod Project folder. Create Mod must keep generating finished game files locally only from the user's
  own installation, and must keep refusing projects that contain game files or game data.
- Tests that run by default must use synthetic data only. Tests that read a local game installation must be opt-in
  (`MK11_GAME`) and must never store game data in the repository.

`.gitignore` is an allowlist, so add each new source file to it on purpose.
